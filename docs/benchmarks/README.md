# Benchmarks

> All metrics derive from committed synthetic fixtures. Real-statement benchmarking never runs in CI.

## Index

- Report: `docs/benchmarks/report.json` (generated by `npm run benchmark`), `docs/benchmarks/report.md`
- Fixtures: `fixtures/synthetic/bdo/expected_extraction.csv` (33 included, 4 excluded), `fixtures/synthetic/bdo/wallet_records_synthetic.csv` (35 post-HITL), `fixtures/synthetic/evaluation/cases.json` (20 cases), `fixtures/synthetic/review/duplicate_cases.json`, `split_cases.json`
- Method: deterministic synthetic-only, CI-validated
- Version: synthetic-bdo-v1, eval-v1

## Methodology

- **Extraction:** Count, precision, recall, F1, excluded-row reconciliation, parser `bdo-visa-gold-ph-image-v1` / format `ocr`/`csv`/`pdf-text`, fixture limits. Row correct only when all required fields match (ID, page, sale date, description, amounts, reference, excerpt presence).
- **Classification:** Total, coverage (non-unknown proposal rate), precision among proposed, unknown rate, malformed/unavailable rate, category support, confidence calibration (bucketed 0–0.6, 0.6–0.8, 0.8–0.95, 0.95–1). Threshold `0.6`; baseline confidence `0.95`; max 5 retrieved examples. Deterministic lexical retrieval + baseline vs fake provider.
- **Duplicates:** Exact key = date + signed centavos + normalized description + normalized reference when both present. Near-match scoring: amount 0.35 + date same/within1 0.25/0.15 + description exact/token Jaccard 0.30 + reference 0.10, threshold ≥0.80, versioned `DUPLICATE_VERSION 1.0.0`. Exact/near/non-duplicate with split-centavo reconciliation.
- **Commit eligibility:** Only approved, valid leaf review items (no containers, excluded/needs-review, missing category, invalid split total, stale history/review) may be dry-run/committed.
- **Fake Wallet:** paginated accounts/categories (limit 200), payloads, mixed `207` envelopes, throttle `429` with `Retry-After`, sync `409`, malformed responses, timeout/unknown, retryable error, no-resend of successes/unknowns, per-`inputIndex` correlation, chunk max confirmed from OpenAPI.
- **Timing percentiles:** Measured extraction, baseline categorization, review initialization, and fake Wallet mapping p50/p95 values are written to `artifacts/benchmark-timing.json`. CI uploads that machine-specific file as an artifact; it is deliberately not committed or release-gating. Manual local-model benchmarking is optional.
- **Reproducibility:** `npm run benchmark` and `npm run eval` are deterministic on same revision; two runs yield identical correctness metrics/schema. CI validates report sections/fixture counts (`scripts/check-external-origins.mjs`, `scripts/check-demo-assets.mjs`, `scripts/check-sensitive-files.mjs`).
- **Non-guarantee statement:** Benchmarks reflect synthetic bias; local-model/OCR variance, no cross-session idempotency, and no cross-Wallet duplicate matching mean real-world results will differ.

## Synthetic-data limits

- Fixture-backed formats only (BDO Visa Gold PHP image); synthetic bias; local-model/OCR variance; no cross-session idempotency; no cross-Wallet duplicate matching; single currency PHP; one statement per request; max 10 MiB file / 30 MiB total / 10 pages / 10k history rows.
- See `docs/guides/parser-authoring.md` for adding a new parser with its own synthetic suite and allowlist.

## Reproduce

```sh
npm ci
npm run benchmark   # deterministic reports plus ignored measured timing artifact
npm run eval        # prints baseline + fake provider metrics
npm run check       # full gate including eval + scans + build
```

README claims must link to this report and qualify results.

## Known limitations (Phase 5)

- Demo is offline and Wallet-disabled by design; real Wallet commit requires explicit confirmation and may show sync delay / rate limiting.
- Diagnostics is redacted, local-only, and never auto-uploaded.
- Accessibility: manual VoiceOver smoke test checklist in `docs/benchmarks/accessibility-checklist.md` (pass/fail only, no sensitive data).
